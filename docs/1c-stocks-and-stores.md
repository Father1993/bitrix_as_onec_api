# 1С → Bitrix: остатки и склады

Адрес API: `https://mk-27.ru/local/tools/as_onec_api.php`. Во всех запросах передавать заголовок `X-Stock-Import-Key`; ключ хранить в константе/защищённой настройке 1С, не в коде.

## Логика обмена

1. Перед запуском и затем по расписанию запросить `GET ?path=/v1/stores`.
2. Построить в 1С соответствие `внешний код склада 1С → store_xml_id Bitrix`.
3. Отправлять абсолютный остаток каждой пары «товар + склад» через `POST ?path=/v1/stocks/import`.
4. Считать пакет успешным только при `HTTP 200`, `ok=true` и `failed=0`. Иначе сохранить `errors[]` и повторить только ошибочные строки после исправления причины.

Не обнуляйте отсутствующие в выгрузке товары: API изменяет только переданные строки. Не передавайте склады брака, транзита и «в пути», если они не должны формировать остаток витрины.

## Склады

Список складов:

`GET ?path=/v1/stores`

В ответе нужны `store_id`, `store_xml_id`, `title`, `active`. Для регулярного обмена используйте `store_xml_id`, а не внутренний `store_id`.

Новый склад можно создать запросом `POST ?path=/v1/stores`:

```json
{"items":[{"store_xml_id":"uuid-склада-1с","title":"Новый склад","address":"Адрес","site_id":"s1","active":true}]}
```

Одинаковый `store_xml_id` обновляет найденный склад, новый — создаёт. На первом запуске не создавайте неизвестные склады автоматически: сначала передайте их в журнал для согласования. После утверждения UUID автосоздание допустимо.

## Остатки

`POST ?path=/v1/stocks/import`

```json
{"items":[{"product_xml_id":"uuid-товара-1с","store_xml_id":"uuid-склада-1с","amount":17}]}
```

`amount` — абсолютное неотрицательное количество. Повтор одной и той же строки безопасен. Проверка товара: `GET ?path=/v1/stocks&xml_id=<uuid-товара-1с>`.

На production 22.09.2026 проверено: товар `c2ed0e2f-f49e-11e6-b2f7-000d88394cae`, склад `11` «Склад ИРТЫШСКАЯ», остаток `17`; складской и общий остатки совпали, повтор прошёл без ошибок.

## BSL-шаблон

Выполнять на сервере 1С. `КлючAPI` получать из защищённой настройки.

```bsl
Функция ВJSON(Данные) Экспорт
    Запись = Новый ЗаписьJSON;
    Запись.УстановитьСтроку();
    ЗаписатьJSON(Запись, Данные);
    Возврат Запись.Закрыть();
КонецФункции

Функция ИзJSON(СтрокаJSON) Экспорт
    Чтение = Новый ЧтениеJSON;
    Чтение.УстановитьСтроку(СтрокаJSON);
    Результат = ПрочитатьJSON(Чтение);
    Чтение.Закрыть();
    Возврат Результат;
КонецФункции

Функция ВызватьAPI(Метод, Ресурс, Тело = Неопределено) Экспорт
    ЗащищенноеСоединение = Новый ЗащищенноеСоединениеOpenSSL();
    Соединение = Новый HTTPСоединение("mk-27.ru", 443, , , , 60, ЗащищенноеСоединение);
    Запрос = Новый HTTPЗапрос("/local/tools/as_onec_api.php?path=" + Ресурс);
    Запрос.Заголовки.Вставить("X-Stock-Import-Key", КлючAPI);
    Запрос.Заголовки.Вставить("Accept", "application/json");

    Если Тело <> Неопределено Тогда
        Запрос.Заголовки.Вставить("Content-Type", "application/json; charset=utf-8");
        Запрос.УстановитьТелоИзСтроки(ВJSON(Тело), КодировкаТекста.UTF8, ИспользованиеByteOrderMark.НеИспользовать);
    КонецЕсли;

    Ответ = Соединение.ВызватьHTTPМетод(Метод, Запрос);
    ДанныеОтвета = ИзJSON(Ответ.ПолучитьТелоКакСтроку());
    Успешно = Ложь;
    Ошибок = 0;
    ДанныеОтвета.Свойство("ok", Успешно);
    ДанныеОтвета.Свойство("failed", Ошибок);
    Если Ответ.КодСостояния <> 200 Или Не Успешно Или Ошибок > 0 Тогда
        ВызватьИсключение "Ошибка обмена с Bitrix: " + ВJSON(ДанныеОтвета);
    КонецЕсли;
    Возврат ДанныеОтвета;
КонецФункции

Процедура ПередатьОстаток(ВнешнийКодТовара, ВнешнийКодСклада, Количество) Экспорт
    Позиция = Новый Структура;
    Позиция.Вставить("product_xml_id", ВнешнийКодТовара);
    Позиция.Вставить("store_xml_id", ВнешнийКодСклада);
    Позиция.Вставить("amount", Макс(0, Количество));
    Позиции = Новый Массив;
    Позиции.Добавить(Позиция);
    Пакет = Новый Структура;
    Пакет.Вставить("items", Позиции);
    ВызватьAPI("POST", "/v1/stocks/import", Пакет);
КонецПроцедуры
```

Для большого обмена добавляйте позиции в один `items` пакет; production-лимиты: до 10 000 строк и 10 MiB, оптимальный размер batch — 100.

После установки версии с журналом сохраняйте `request_id` из каждого POST-ответа. Владелец сайта смотрит последние операции через `GET ?path=/v1/audit/requests&limit=50` или вкладку «Журнал обмена» в настройках модуля. В раскрытой записи есть безопасные диагностические поля (хэш и размер тела, строки с ошибками, ответ API); ключ, пароль и полное тело запроса не сохраняются.

## Цены

`POST ?path=/v1/prices`. Одной строкой передаётся одна цена одного типа:

```json
{"items":[{"product_xml_id":"uuid-товара-1с","catalog_group_id":1,"price":30112,"currency":"RUB"}]}
```

Типы цен: `1` — Розничная Ф; `17` — Сахалин РОЗНИЦА; `16` — Оптовые; `2` — Сахалин ОПТ. Проверка: `GET ?path=/v1/prices&xml_id=<uuid-товара-1с>`.
